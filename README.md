## 🚀 Troubleshooting common issues

If you encounter problems, look at these solutions first.

If the application fails to start, ensure your antivirus software does not block the file. Sometimes, security tools flag new software by mistake. You can create an exception in your settings for the Voidstrap folder.

If the game does not open after you click play, check your internet connection. A weak signal can prevent the bootstrapper from downloading the required files from the central server. You can try to reset your configuration by deleting the contents of the `Voidstrap` folder in your `%localappdata%` directory.

If you notice visual glitches in the game, try resetting your graphic settings in the Voidstrap menu. Sometimes, old cache files conflict with new updates. Clearing the cache often fixes these display issues.

## 📋 Frequently asked questions

**Does this software get me banned?**
No. Voidstrap acts as a launcher. It does not inject code into the game engine in a way that provides an unfair advantage. Thousands of users run it to improve performance.

**Will my settings stay the same after an update?**
Yes. Your configuration file saves to your local documents folder. When a new version of the launcher arrives, it reads your existing file so you do not have to set up your preferences again.

**Can I stop using it?**
Yes. If you decide to remove Voidstrap, simply run the uninstaller from your Windows Control Panel. You can reinstall the standard launcher by downloading it again from the official website.

**Does it work on Windows 7?**
The launcher requires features present in newer versions of Windows. We recommend using it on Windows 10 or 11 for the best experience and security.
